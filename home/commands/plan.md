Make an implementation plan for: $ARGUMENTS

- 3 to 6 numbered steps naming the exact files.
- The tests you'll add or change, written first.
- Edge cases and how you'll handle them.
- One-line trade-off if there's more than one reasonable approach.
Then stop and wait for my go-ahead.
